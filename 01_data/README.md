# 01_data — 원본 데이터 받는 방법

이 폴더의 CSV 파일은 **개인정보(연구자 실명 + 연구자번호)를 포함하므로 저장소에 커밋되지 않는다**
(`.gitignore`로 제외). 아래 두 파일을 공공데이터포털에서 직접 받아 이 폴더에 넣어야 노트북이 동작한다.

## 필요한 파일

| 파일명 | 제공기관 | 건수 | 주요 컬럼 |
|---|---|---|---|
| `특구입주기업현황.csv` | 연구개발특구진흥재단 | 6,359 | 번호 / 지역 / 기관명 / 지구 |
| `이알앤디_과제정보.csv` | 한국연구재단 | 11,788 | 사업년도 / 선정년도 / 대·중·소·세부사업명 / 과제명 / 연구책임자명 / 연구자번호 / 주관기관명 / 보안과제여부 |

- 출처: 공공데이터포털 (<https://www.data.go.kr>)
- 조달 방식: **CSV 수동 다운로드** (Open API 서비스키 연동은 범위에서 제외됨)
- 파일명은 위와 정확히 일치해야 한다 (코드가 이 이름으로 읽음)

## 인코딩 (주의)

두 파일 모두 **cp949**다. UTF-8로 열면 `UnicodeDecodeError`가 발생한다.

```python
pd.read_csv("01_data/특구입주기업현황.csv", encoding="cp949")
```
